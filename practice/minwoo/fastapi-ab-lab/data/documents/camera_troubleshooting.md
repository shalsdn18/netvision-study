# 카메라 장애 대응 안내

> 이 문서는 로컬 RAG 동작을 확인하기 위한 학습용 예시이며 실제 회사 규정이 아닙니다.

카메라 영상이 나오지 않으면 다음 순서로 확인합니다.

1. 카메라 전원 표시등이 켜져 있는지 확인합니다.
2. 랜 케이블이 카메라와 네트워크 장비에 단단히 연결되어 있는지 확인합니다.
3. 등록된 카메라 IP 주소로 Ping을 보내 네트워크 응답을 확인합니다.
4. RTSP 서비스에 사용하는 554번 포트가 열려 있는지 확인합니다.
5. 전원과 네트워크가 정상이지만 영상이 없으면 카메라를 재시작하고 상태를 다시 확인합니다.

장애 기록에는 확인 시각, 카메라 이름, IP 주소, Ping 결과, 554번 포트 확인 결과를 남깁니다.
