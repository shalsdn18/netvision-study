# FastAPI와 Ollama 실습 구조

> 이 문서는 로컬 RAG 동작을 확인하기 위한 학습용 예시입니다.

서비스 A는 기본 포트 8001에서 사용자 요청을 받는 진입점 역할을 합니다. 서비스 B는 기본 포트 8002에서 텍스트 처리, 서비스 C 호출, Ollama 연동을 담당합니다. 서비스 C는 기본 포트 8003에서 최종 결과를 저장합니다.

로컬 Ollama 서버는 11434번 포트에서 실행됩니다. 텍스트 생성에는 `qwen2.5:7b-instruct-q4_K_M` 모델을 사용하고 문서와 질문의 임베딩에는 `nomic-embed-text:latest` 모델을 사용합니다.

전체 REST 호출 흐름은 A에서 B를 거쳐 C로 이어집니다. RAG 질의는 서비스 B가 로컬 문서를 검색하고 검색된 자료를 Qwen 모델에 전달하여 답변과 출처를 반환합니다.
