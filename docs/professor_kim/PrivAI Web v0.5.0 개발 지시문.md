# PrivAI Web v0.5.0 개발 지시문

`PrivAI_v050.html`이라는 이름의 로컬 문서 기반 AI 앱을 작성하라.

이 앱은 사용자가 자신의 문서를 브라우저에 등록하고, 문서 안에서 관련 내용을 검색한 뒤, WebLLM 또는 추출형 방식으로 답변을 생성하는 프로그램이다.

HTML, CSS, JavaScript를 모두 하나의 HTML 파일에 포함하고, 별도의 설치나 빌드 없이 실행할 수 있게 작성한다.

## 1. 기본 실행 환경

- PC Chrome·Edge와 Android Chrome에서 사용할 수 있어야 한다.
- 스마트폰과 PC 화면에 모두 맞는 반응형 UI로 작성한다.
- 기본 저장소는 IndexedDB를 사용한다.
- IndexedDB를 사용할 수 없으면 메모리 모드로 자동 전환한다.
- 문서와 검색 데이터는 사용자의 브라우저 안에 저장한다.
- 문서 원문과 질문을 외부 서버로 전송하지 않는다.

## 2. 화면 구성

다음 5개 탭을 만든다.

- Chat
- Documents
- Workspace
- Models
- Settings

라이트 모드와 다크 모드를 지원한다.

## 3. 문서 등록

다음 파일 형식을 지원한다.

- TXT
- MD
- CSV
- HTML
- PDF
- DOCX

사용자는 파일 여러 개 또는 폴더를 선택할 수 있어야 한다.

문서를 등록하면 다음 순서로 처리한다.

문서 읽기  
→ 텍스트 추출  
→ 청크 분할  
→ 로컬 임베딩 생성  
→ IndexedDB 저장

PDF는 PDF.js, DOCX는 Mammoth.js를 사용한다. 필요한 경우에만 CDN에서 불러온다.

## 4. 문서 관리

Documents 화면에서 다음 정보를 표시한다.

- 파일명
- 파일 형식
- 청크 수
- 문자 수
- 파일 크기
- 색인 시각

다음 기능도 제공한다.

- 개별 문서 색인 삭제
- 현재 Workspace 전체 문서 삭제
- 임베딩 재생성
- 현재 Workspace 색인 내보내기

원본 파일은 삭제하지 않는다.

## 5. Workspace

Workspace는 문서 묶음을 구분해서 관리하는 기능이다.

다음 기능을 제공한다.

- Workspace 생성
- Workspace 선택
- Workspace 삭제
- Workspace별 문서 수와 청크 수 표시

기본 Workspace 이름은 `Default`이며 삭제할 수 없게 한다.

## 6. 문서 검색

다음 3가지 검색 방식을 제공한다.

- Keyword
- Semantic
- Hybrid

Semantic 검색은 256차원 해시 기반 로컬 희소 임베딩을 사용한다.

Hybrid 검색은 키워드 점수와 의미 유사도 점수를 함께 사용한다.

검색 결과에는 다음 내용을 표시한다.

- 파일명
- 페이지 또는 청크 번호
- 키워드 점수
- 의미 점수
- 총점
- 관련 문서 내용

비슷하거나 중복된 결과는 하나만 표시한다.

## 7. RAG 답변

사용자가 질문하면 다음 순서로 자동 실행한다.

1. 관련 문서 검색
2. RAG 지시문 생성
3. WebLLM 질의
4. 답변 표시

RAG 지시문은 다음 원칙을 따른다.

- 검색된 문서 내용을 우선 사용한다.
- 문서에 없는 내용은 추측하지 않는다.
- 확인할 수 없으면 `문서에서 확인되지 않습니다`라고 답한다.
- 답변은 한국어로 작성한다.
- 답변 끝에 사용한 파일명을 표시한다.

생성된 RAG 지시문은 내부에 저장하고 TXT 파일로 내보낼 수 있게 한다.

## 8. 답변 엔진

답변 방식은 다음 2가지만 제공한다.

- WebLLM
- 추출형 답변

WebLLM이 실행되지 않거나 오류가 발생하면 자동으로 추출형 답변으로 전환한다.

## 9. WebLLM

WebLLM은 다음 조건에서만 실행한다.

- HTTPS 주소
- localhost
- WebGPU 지원 브라우저

다음 환경에서는 실행하지 않고 이유를 안내한다.

- file://
- content://
- 일반 HTTP 주소
- WebGPU 미지원 브라우저

Android 기본 모델은 다음 모델로 한다.

`Qwen2.5-0.5B-Instruct-q4f32_1-MLC`

다음 기능을 제공한다.

- 모델 선택
- 최대 토큰 선택
- 모바일 안정 모드
- 짧은 응답 모드
- 모델 로드
- 답변 스트리밍
- 답변 중지
- WebLLM 리셋

모델은 사용자가 `모델 로드` 버튼을 눌렀을 때만 다운로드한다.

## 10. 추출형 답변

WebLLM을 사용할 수 없을 때 문서에서 관련 문장을 직접 추출해 답변한다.

다음 기준으로 처리한다.

- 질문 단어가 많이 포함된 문장을 우선 선택한다.
- 여러 문서에서 핵심 문장을 최대 5개 정도 선택한다.
- 각 문장 뒤에 파일명과 페이지 또는 청크 번호를 표시한다.
- 문서에 없는 해석은 추가하지 않는다.

## 11. Chat 화면

Chat 화면에는 다음 기능을 제공한다.

- Workspace 선택
- 검색 방식 선택
- 질문 입력
- 문서 수, 청크 수, 문자 수 표시
- 로컬 AI 답변 실행
- 검색 진행 단계 표시
- 답변 복사
- 답변 중지
- 답변 숨기기
- 대화 기록 표시
- 대화 기록 삭제
- 검색 근거 접기·펼치기

`Ctrl+Enter` 또는 `Command+Enter`로 답변을 실행할 수 있게 한다.

## 12. 설정과 데이터 관리

다음 설정을 제공한다.

- Top-K 검색 결과 수
- 최대 Context 문자 수

다음 데이터 관리 기능도 제공한다.

- 전체 색인 내보내기
- 전체 색인 가져오기
- 설정 내보내기
- 설정 가져오기
- RAG 지시문 저장
- 전체 로컬 데이터 삭제

전체 데이터를 삭제해도 원본 문서 파일은 삭제하지 않는다.

## 13. 오류 처리

다음 오류가 발생해도 앱 전체가 멈추지 않게 한다.

- IndexedDB 오류
- 문서 없음
- 지원하지 않는 파일
- PDF 또는 DOCX 파서 로드 실패
- WebGPU 미지원
- WebLLM 로드 실패
- 모델 다운로드 실패
- WebLLM 응답 오류
- 빈 답변
- 클립보드 복사 실패
- 잘못된 색인 파일 가져오기

오류는 사용자가 이해할 수 있는 한국어 메시지로 표시한다.

## 14. 반드시 제거할 기능

다음 내용은 코드와 화면에서 모두 제거한다.

- WALT
- `/news`
- WALT 프록시
- WALT URL
- WALT Timeout
- WALT 테스트 버튼
- WALT와 WebLLM 경쟁 실행
- WALT 관련 함수와 상태 표시

## 15. 완성 기준

다음 기능이 모두 정상 작동해야 한다.

- 문서 등록과 색인
- Workspace별 문서 관리
- Keyword·Semantic·Hybrid 검색
- 검색 근거 표시
- RAG 지시문 생성
- WebLLM 답변
- 추출형 대체 답변
- 색인 내보내기·가져오기
- 모바일·PC 반응형 화면
- 라이트·다크 모드
- 주요 오류 안내

기존의 정상적인 로컬 문서 검색 기능은 유지하되, 중복 코드와 잘못된 DOM 참조는 정리하라.

최종 결과는 설명문이 아니라 즉시 실행 가능한 완전한 `PrivAI_v050.html` 파일로 제공하라.
